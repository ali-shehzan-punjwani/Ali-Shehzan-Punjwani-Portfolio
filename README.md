## 🚀 Featured Projects

This portfolio highlights several AI and cybersecurity projects, including:

### 🛡️ STAR Bot
An AI-powered Cybersecurity Assistant built using Retrieval-Augmented Generation (RAG), FAISS Vector Search, Sentence Transformers, Groq API, and Llama 3.1 to provide context-aware cybersecurity guidance.

### 🚨 STAR PhishGuard AI
An intelligent phishing email detection system that combines Natural Language Processing (NLP), Machine Learning (Logistic Regression), and Deep Learning (MLP Neural Network) to identify phishing emails and assess security risks through an interactive Streamlit application.

### ☁️ Cloud Security Projects
Hands-on cloud computing and cloud security projects developed using AWS services, focusing on secure cloud infrastructure, deployment, and best practices.

### 🔐 SOC & Blue Team Projects
Security Operations Center (SOC) projects involving threat monitoring, log analysis, incident detection, vulnerability management, and defensive security techniques.
