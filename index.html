Read the full abstract

Phishing emails try to steal information or persuade people to take unsafe actions. This study examines how STAR PhishGuard Pro checks emails and explains its results. The reviewed code uses manually chosen rules. The review did not identify trained-model inference or an active Gemini call in the inspected paths, although the interface includes machine-learning confidence fields. The source manuscript reports four small checks. They show a misleading reason for normal safety advice, a positive authentication verdict when results are missing, a simulated file hash that changes, and loss of a hidden HTML link destination. These checks reveal specific implementation problems; they do not measure overall detection accuracy. The paper also proposes a fair comparison of original rules, repaired rules, trained machine learning, a prompted large language model, and a selective hybrid. The plan covers suitable data, duplicate control, shared inputs, detection errors, unanswered cases, time, cost, and repeatable records. The full comparison has not been performed, so no method is claimed to be the best.
