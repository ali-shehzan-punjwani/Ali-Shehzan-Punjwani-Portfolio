Research Paper — In Progress

AI-Driven Cloud Security Monitoring and Automated Incident Response System Using AWS CloudTrail and Machine Learning Techniques

This research focuses on developing an intelligent cloud security monitoring framework capable of automatically detecting suspicious activity from AWS CloudTrail logs using machine learning algorithms, while generating automated incident response recommendations.

  • Analyzing AWS CloudTrail logs to identify patterns indicative of suspicious or unauthorized activity within cloud environments.
  • Applying machine learning algorithms to classify and detect anomalies in cloud access and usage behavior.
  • Designing an automated incident response mechanism that generates actionable recommendations based on detected threats.
  • Evaluating the framework's effectiveness in reducing response time and improving cloud security posture for organizations.

Research Paper — In Progress

Comparative Analysis of Machine Learning and Deep Learning Models for AI-Based Phishing Email Detection Using Natural Language Processing

Conducting research on AI-driven phishing email detection by comparing Machine Learning and Deep Learning algorithms for cybersecurity applications.

  • Investigating the performance of Logistic Regression, Naïve Bayes, Support Vector Machine (SVM), Random Forest, and Multilayer Perceptron (MLP) using TF-IDF-based text representations.
  • Evaluating models using Accuracy, Precision, Recall, F1-score, Confusion Matrix, and computational efficiency to identify the most effective approach for phishing detection.
  • Exploring the integration of Natural Language Processing (NLP) techniques to improve automated email threat classification and support intelligent cyber defense systems.
